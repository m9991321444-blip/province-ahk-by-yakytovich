# 🚔 AHK-биндеры для MTA Province (Сервер #5) | by yakytovich

Набор современных, настраиваемых AHK-скриптов для государственных организаций и собеседований на проекте **MTA Province**.

## 📦 Доступные скрипты в паке

* **ГУ МВД (ППС / ОСН / УЦ)** (`гувд ахк by yakytovich.rar`) — полный комплект отыгровок, тен-коды, 23 лекции, экзамены ОСН, ПМП, шпаргалка по УК РП, КоАП, ФЗоП и ТК РП.
* **УГИБДД (ОР / СР / МР)** (`гибдд бу якутович.rar`) — оформление ДТП, тауметр, алкотестер, рейды Спецроты, областной патруль, тен-коды и актуальные ссылки 5-го сервера.
* **Проведение собеседований** (`собес ахк by yakytovich.rar`) — быстрая проверка паспорта, трудовой, диплома, медкарты, военного билета, РП-терминов и выдача формы.

## ✨ Особенности сборки

* **Настройка клавиш под себя.** Любой бинд меняется прямо в окне программы без редактирования кода.
* **Удобная анкета.** Автоподстановка ФИО, звания, города, тен-кода и пола персонажа (окончания в `/me` меняются автоматически).
* **Выбор темы интерфейса.** 4 темных цветовых схемы на выбор.
* **Умная раскладка.** Скрипты сами переключают раскладку на русскую перед отправкой текста в чат.

## 🚀 Как установить и запустить

1. Установите **AutoHotkey v1.1** (выбирайте вариант *Unicode 32-bit* или *ANSI 32-bit*).
2. Скачайте нужный архив из списка выше и распакуйте его в отдельную папку.
3. Запустите `.ahk` файл **от имени администратора** (ПКМ -> *Запуск от имени администратора*).
4. Нажмите `Insert` в игре, чтобы открыть или свернуть меню, и заполните **Анкету**.
